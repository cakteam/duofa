# 内容目录格式

多发不帮你做视频，只负责「把做好的视频和文案填进各平台的发布页」。它从一个**内容目录**里读东西，目录按下面的约定摆放即可。
自带的 `示例内容/` 就是一份完整的例子，照着改最快。

```
内容目录/                         ← config.json 里的 contentDir
├── 1101/                         ← 日期目录：1101，或 2026-11-01、20261101
│   ├── 1101-1-猫为什么爱踩奶/     ← 一条内容（文件夹名随意，按名字排序）
│   │   ├── 成片.mp4               ← 视频
│   │   ├── 发布文案.txt           ← 标题、正文、话题、发布时间
│   │   ├── 3x4封面.png            ← 竖封面（可选）
│   │   └── 4x3封面.png            ← 横封面（可选）
│   ├── 1101-2-一分钟看懂潮汐/
│   │   └── …
│   └── B站/                      ← 名字里带「B站」的文件夹 = 一条 B站内容（可选）
│       ├── B站.mp4
│       ├── B站发布文案.txt
│       └── B站封面.png
└── 数据下载/                      ← 「数据」页下载的数据默认放这里（自动创建）
```

## 日期目录

- 名字以 4 位数字开头才算：`1101`（月日）、`2026-11-01`、`20261101` 都可以。
- 只写月日时，年份按今年算；如果这个日期已经过去 60 天以上，就当成明年。想写死年份就用 `2026-11-01` 这种写法。
- 发布页左上角的下拉框就是在这些日期目录之间切换；日历也按它们排。

## 一条内容

日期目录下的每个子文件夹，只要里面有**视频**或**发布文案**就算一条。名字以「素材」结尾、以 `.` 或 `_` 开头的文件夹会被跳过。

| 文件 | 规则 |
| --- | --- |
| 视频 | 优先找 `成片.mp4` / `成片.mov` / `成片.m4v`；没有就取文件夹里最大的 `.mp4/.mov/.m4v` |
| 发布文案 | 文件名里带「发布文案」的 `.txt`，如 `发布文案.txt`、`发布文案与素材源地址.txt` |
| 竖封面 | `3x4封面*.png`（3:4） |
| 横封面 | `4x3封面*.png`（4:3） |

普通内容发往**视频号、抖音、快手**；B站内容（见下文）只发往 **B站**。

## 发布文案.txt

用【】标出各段，顺序随意，没有的段落可以不写：

```
【标题】
猫为什么爱踩奶？
答案藏在小时候

【视频号短标题】
猫为什么爱踩奶

【标红钩子词】：踩奶

【正文】
猫咪踩奶是小时候吃奶时留下的习惯……
#猫 #萌宠 #冷知识

【建议发布时间】
11月1日 08:30
```

| 段落 | 用途 |
| --- | --- |
| 【标题】 | 可以写多行，合起来就是完整标题。抖音标题取前 30 字 |
| 【视频号短标题】 | 可选。视频号短标题限 6–16 字；不写时用完整标题，超长就取其中一整行，不在句子中间截断 |
| 【正文】 | 视频号、抖音、快手的描述 |
| 【视频简介】或【简介】 | 可选。写了就用它代替【正文】作描述 |
| `#话题` | 写在文案任何位置都行，取前 6 个。描述里的 `#话题` 会被拿掉，再由各平台的话题功能单独加上（抖音最多 5 个、快手 4 个、B站 10 个） |
| 【标红钩子词】 | 可选。只用于看板里把你的内容和平台作品对上号 |
| 【建议发布时间】 | 写在下一行。`11月1日 08:30`、`2026-11-01 08:30`，或只写 `08:30`（日期取所在的日期目录） |

> 注意：正文里不要出现「【建议发布时间】」这几个字，否则会被当成发布时间那一段。

## B站内容

文件夹名里带「B站」（如 `B站`、`B站部分`）的是一条 B站内容：

| 文件 | 规则 |
| --- | --- |
| 视频 | `B站.mp4` 或 `1101-B站.mp4`（也可以是 .mov/.m4v） |
| 发布文案 | 文件名里带「发布文案」的 `.txt`，格式同上：【标题】（≤80 字）【简介】`#标签`【建议发布时间】 |
| 封面 | `B站封面*.png`（16:9） |

B站的分区需要你在发布页上手动选；定时只能按 5 分钟一档、距现在 5 分钟到 15 天之内。

## 封面怎么用

| 平台 | 用哪张 |
| --- | --- |
| 视频号 | 一张：默认 3:4 竖封面（个人主页卡片），没有就用 4:3（动态封面） |
| 抖音 | 两张：竖封面 3:4 + 横封面 4:3 |
| 快手 | 一张：优先竖封面 |
| B站 | `B站封面*.png` |

界面上点缩略图可以换选或选「不上传」（让平台自动选帧）。封面上传失败只会告警，不影响其他内容。

## 在界面上改

标题、描述、话题、定时、封面都能在发布页上直接改，改动自动保存在浏览器里（不写回你的文件）；
刷新、换日期、重启后都还在。日历上把一条拖到别的日期，就是改它的定时日期（保留原来的时刻）。
